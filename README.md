 🏠 ex026Imoveis

Um pequeno projeto em JavaScript puro para cadastrar e listar imóveis, criado com o objetivo de praticar manipulação do DOM, orientação a objetos e estruturação de componentes de forma limpa.

## ✨ Funcionalidades

- Adicionar imóveis informando tipo, área e status de aluguel.
- Visualizar todos os imóveis cadastrados.
- Remover imóveis da lista.
- Manipulação dinâmica do DOM com `appendChild`, `classList`, `setAttribute`, entre outros métodos.

## 🧠 Conceitos praticados

- Manipulação do DOM
- Criação de classes em JavaScript
- Eventos (click)
- Organização de código com orientação a objetos
- Uso de `classList`, `remove()`, `createElement()`, `appendChild()`

## 🚀 Tecnologias

- HTML5
- CSS3
- JavaScript (ES6+)

## 📷 Demonstração

O usuário preenche um formulário com os dados do imóvel e, ao clicar no botão de cadastrar, o imóvel é adicionado à lista com a opção de remoção individual.
